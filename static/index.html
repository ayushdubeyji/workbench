2.8" SPI TFT LCD (ILI9341 / ST7789) Wiring Guide

Wiring specification for the 2.8-inch SPI TFT display on Raspberry Pi 4B+ (SPI0 Bus):

TFT Pin Function Pi 4B+ Pin Pi GPIO / Name
VCCPower InPin 13.3V PWR (or 5V if module has onboard 3.3V LDO)
GNDGroundPin 6GND (or pins 9, 14, 20, 25, 30, 34, 39)
CSChip SelectPin 24GPIO 8 (SPI0 CE0)
RESETHardware ResetPin 18GPIO 24
DC / RSData / CommandPin 22GPIO 25
SDI (MOSI)SPI Data InPin 19GPIO 10 (SPI0 MOSI)
SCK (SCLK)SPI ClockPin 23GPIO 11 (SPI0 SCLK)
LED (BL)BacklightPin 173.3V (or GPIO 18 for PWM dimming)
SDO (MISO)SPI Data OutPin 21GPIO 9 (SPI0 MISO, optional if no touch)
To enable SPI on Raspberry Pi: Run sudo raspi-config nonint do_spi 0. Full driver and firmware daemon script available in SOLDERING_DISPLAY_WIRING.md.
